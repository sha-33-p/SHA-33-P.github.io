# 大麦抢票助手（手机本地版）

一个**直接在安卓 / 华为手机浏览器里运行**的演唱会抢票可视化助手。
无需电脑、无需服务器，所有数据只存在你这部手机里。

---

## 一、它能做什么

- 📱 手机浏览器打开即用，安卓（含华为鸿蒙）通用
- ⏱ 设置开售时间，到点自动打开大麦购票页
- 🤖 自动点击「立即购买 → 选场次 → 选票档 → 提交订单」
- 💳 可选自动点「去支付」跳到支付宝（支付需本人确认）
- 🔒 账号密码在本机用 Web Crypto 加密存储，不上传任何服务器

## 二、怎么用

1. 把本目录（`index.html` + `app.js`）放到手机能访问的地方：
   - 最简：用手机浏览器直接打开本地的 `index.html`（通过文件管理器/网盘）；
   - 或：部署到任意静态空间（GitHub Pages / 对象存储 / 内网），手机访问网址。
2. 填写大麦账号（仅本机保存）、演出链接、场次、票档、数量、观看人、开售时间。
3. 点「保存配置」。
4. 点「开始抢票」，保持本页面与前弹出的购票页不被关闭。
5. 到点自动执行；支付环节请本人确认。

> ⚠️ 浏览器会拦截新窗口，首次请允许本站点「弹出窗口」。

## 三、重要限制与合规提示

- 浏览器内的脚本**无法读取大麦原生 App 的内部界面**，只能在打开的 H5 页里模拟点击；
  大麦若跳转到原生 App，自动点击会中断，需手动接管（页面有日志提示）。
- 频繁自动化可能触发大麦风控（验证码、限流、账号风险）。请仅用于本人合法购票。
- 本工具按"辅助 + 本人最终确认支付"设计，**不绕过任何安全验证**。

## 四、想要更彻底的"原生 App 自动点击"？

若需在**安卓手机上直接控制大麦 App 内部**（而非 H5 页），需用安卓端的
无障碍自动化方案（手机本地运行，无需电脑）：

- **Auto.js / 振飞脚本**：在手机安装 Auto.js App，把购票点击逻辑写成 JS，
  通过无障碍服务控制大麦 App，可精确按控件 id/文本点击。
- **Tasker + AutoInput**：图形化配置触发与点击。
- 华为鸿蒙对无障碍自动化管控较严，可能需在「设置→无障碍」手动授予权限，
  且部分机型后台会被杀，建议保持屏幕常亮、关闭省电限制。

> 这类方案涉及对第三方 App 的自动化操作，请务必遵守平台用户协议与当地法规，
> 仅用于个人学习研究，风险自负。

## 四-B、大麦 App 自动点击脚本（安卓本地 · 可视化版，成功率更高）

`../damai_app_autoclick.js` 是一份在安卓手机本地运行的 **Auto.js / 振飞脚本**，
直接控制大麦 **原生 App** 内部控件（按文本点击），比网页 H5 方案成功率更高。
**已做成可视化界面**：在手机上弹出表单窗口，像网页控制台一样填参数，无需改代码。
同样做到「抢+锁票+点去支付」后**由本人完成支付**。

### 手机操作步骤

1. **安装脚本引擎**
   - 安卓手机安装 **Auto.js** 或 **振飞脚本**（华为鸿蒙需手动授权）。
2. **授权**
   - 打开脚本引擎 → 「无障碍服务」→ 开启本 App 的无障碍权限；
   - 同样授予「悬浮窗」权限（用于界面/日志显示）。
3. **导入并运行脚本**
   - 在脚本引擎里「导入」`damai_app_autoclick.js` 并运行；
   - 手机会弹出**可视化窗口**：填写演出链接(`damai://`)或演出名、场次、票档、数量、
     支付工具(下拉)、开售时间，勾选「设备有锁屏密码」(如有)。
4. **保活**
   - 手机「设置→电池/省电」把脚本引擎设为**不限制/忽略电池优化**；
   - 保持**屏幕常亮**（开发者选项→不息屏），开售前不要锁屏，大麦 App 保持已登录。
5. **开始**
   - 点窗口里「▶ 开始抢票」；脚本会等至开售时间自动：
     解锁→启动大麦→进详情→立即购买→选场次→选票档→
     提交订单（**最多重试 15 次**）→选支付工具→点去支付。
   - 窗口底部实时显示日志；可随时点「■ 中止」。
6. **本人支付**
   - 脚本停在点「去支付」后，手机弹出系统支付选择框，**你本人点允许打开→付款**。
   - 若自动提交一直未锁定，手机会**震动+日志报警**，请立刻在 App 里手动猛点「提交订单」。

> 控件文本/Deep Link 因大麦版本、机型而异，首次建议先在「非开售」演出上试运行一遍，
> 核对各项点击是否命中，再用于正式抢票。
> 仅在本人手机、本人账号下用于学习研究，遵守平台规则，风险自负。

## 五、自动获取场次/票档/开售时间（下拉框）

由于浏览器同源限制，助手页无法直接读取大麦页面内容。采用**书签桥接**方案：

1. 在助手页点「复制抓取书签」，把得到的 `javascript:` 链接添加到浏览器**书签栏**（命名如"抓取大麦"）。
2. 在手机/电脑浏览器打开大麦**演出详情页**，点击该书签。
3. 脚本读取页面里的场次列表、票档、开售时间，写入本机 `localStorage`。
4. 切回助手页（同一浏览器），场次/票档下拉框自动填充，开售时间自动填入，演出链接自动填入当前 URL。
5. 若两个页面在同一浏览器不同标签页，写入会通过 `storage` 事件实时同步。

> 抓取依赖大麦页面 DOM 文本特征，若大麦改版导致抓不到，可手动在下拉里选/填。
> "开售时间"若页面只显示"即将开售"无具体时间，则抓不到，需手填。

## 六、配套：登录页跳转脚本（同目录）

`alipay_login_autoclick.js` 是一份**在安卓手机本地运行**的 Auto.js / 振飞脚本（**可视化版**），
用于"解锁→启动 App→进入登录页"（不自动填密码，合规）。支持支付宝/微信。

用法：
1. 手机安装 Auto.js / 振飞脚本 App，授予无障碍 + 悬浮窗权限。
2. 把 `alipay_login_autoclick.js` 导入 App 运行，手机会弹出可视化窗口。
3. 选择目标 App（支付宝/微信）、勾选是否有锁屏密码，点「开始跳转」。
4. 脚本解锁屏幕、打开 App 并点击登录入口，停在登录页由本人输入账号密码。

> 该脚本控件文本按通用规则编写，不同机型可能需微调。
> 仅在本人手机、本人账号下用于学习研究，遵守平台规则。
